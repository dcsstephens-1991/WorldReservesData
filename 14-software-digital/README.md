# 14 — Software & Digital Tools

This is the "how to actually read this drive" folder.

## Contents
- `zim/` — Kiwix ZIM archives (populated by `scripts/download-kiwix.sh`)
- `readers/` — portable copies of Kiwix Desktop installers (Windows/Mac/Linux), a PDF reader, an EPUB reader, for offline install with no app store access
- `recovery-tools/` — testdisk/photorec or similar, in case a copy of this drive gets corrupted
- `os-images/` — optional: a lightweight Linux live-CD ISO, useful if a working computer needs an OS from scratch

## Note
Keep installers for at least two platforms (Windows + Linux) since you can't predict what hardware survives.
