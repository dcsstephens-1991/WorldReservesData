# 04 — Food & Agriculture

## Subtopics
- `growing/` — soil, seed saving, crop rotation, permaculture, greenhouse/climate-specific growing
- `foraging/` — see also `05-plants-fungi/` for identification
- `animal-husbandry/` — chickens, goats, rabbits, bees; feed, shelter, breeding, disease
- `preservation/` — canning, drying, root cellaring, smoking, curing, fermentation
- `hunting-fishing-trapping/`
- `tools-equipment/` — hand tools, small-scale mechanization, repair

## Recommended sources
- USDA / land-grant university extension office bulletins (public domain)
- Project Gutenberg pre-1930 farming/homesteading texts
- "The Have-More Plan", "Storey's Guide to..." series (check licensing per title)
- FAO manuals on smallholder agriculture (open access)
