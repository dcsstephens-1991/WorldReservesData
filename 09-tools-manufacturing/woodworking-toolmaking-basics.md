# Woodworking & Tool-Making Basics

Complements `07-shelter-construction/basic-carpentry-joinery.md` (structural focus) with a tool- and craft-making focus.

## Hand tools worth prioritizing (in rough order of general usefulness)
1. **Axe** — felling, splitting, rough shaping; arguably the single most versatile wood tool.
2. **Knife** — general-purpose cutting, carving, fine work.
3. **Saw** — controlled, precise cuts that an axe can't achieve.
4. **Chisels** — precise material removal, joinery work.
5. **Drawknife** — efficient shaping of round/curved stock (tool handles, spokes, bows).
6. **Hand drill/auger** — holes for pegs, joinery.

## Tool handle making
- A well-fitted handle (haft) is as important as the tool head itself — a loose or poorly shaped handle is both inefficient and dangerous (risk of the head flying off during use).
- Straight-grained wood, selected so the grain runs parallel to the length of the handle (not diagonally across it), resists breaking under stress far better than a handle cut without attention to grain direction.
- A wedge (wood or metal) driven into a slot at the top of the handle, inside the tool head's eye, is the traditional method for locking a handle in place permanently.

## Basic carved/shaped items worth knowing as building-block skills
- **Wooden pegs/dowels** — for joinery (see `basic-carpentry-joinery.md`).
- **Wedges** — for splitting wood, tool handle locking, and other mechanical-advantage uses.
- **Spoons and basic containers** — foundational carving practice that transfers directly to more complex shaping tasks.
- **Wooden gears/mechanical parts** — for simple machinery (see `08-energy-power/mechanical-power-basics.md`), a more advanced application of the same shaping skills.

## Wood selection
- See `07-shelter-construction/basic-carpentry-joinery.md` for general wood property notes — the same rot-resistance and grain principles apply to tool-making, with an added emphasis on shock resistance (a tool handle needs to absorb repeated impact without cracking, a property that varies significantly by species).
