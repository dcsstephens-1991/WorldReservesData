## Curation note
Highest-caution category in the archive. Every entry needs: region, season, multiple distinguishing features (not just photos), common toxic look-alikes named explicitly, and source citation. See `docs/CURATION.md`.

## Recommended sources
- Regional agricultural extension office foraging guides
- Wikipedia species pages (ZIM) cross-referenced with a dedicated field guide
- Peterson Field Guide series (check licensing — likely reference-only, not redistributable)
