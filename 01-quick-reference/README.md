# 01 — Quick Reference

The "first 72 hours" layer. Small, printable, phone-friendly. This is the last thing you compile (it summarizes folders 02-13) but the first thing anyone should open.

## Contents to build
- `triage-and-first-aid-card.md` — one-page ABCs, bleeding control, shock, CPR steps
- `water-purification-quicksteps.md` — boil times, bleach ratios, filtration order of operations
- `edible-plant-quick-id_[region].md` — regional, photo-referenced, "when in doubt don't"
- `fire-shelter-signal.md` — fire starting methods, emergency shelter types, signaling for rescue
- `evacuation-bugout-checklist.md`
- `master-index.md` — one-page map of the entire drive with folder descriptions

## Format
Markdown, one page each when printed. No dependency on opening large PDFs/ZIMs.
