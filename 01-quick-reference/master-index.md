## How content is organized
- Each numbered folder has its own `README.md` describing what's inside and where it came from.
- Bulk reference material lives as **Kiwix ZIM files** in `14-software-digital/zim/` — open with the Kiwix app included in the same folder.
- Anything written specifically for this archive (like this page) is plain markdown — readable in any text editor, even without Kiwix.

## If you have no working device
Print `01-quick-reference/` — it's designed to fit on a handful of pages and covers the highest-priority, time-critical information.
